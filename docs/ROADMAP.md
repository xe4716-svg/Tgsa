# V1.0 实施路线

1. 基础底座：API、PostgreSQL、Redis、租户 RLS、账号和代理模型（骨架已建立）。
2. Telegram 登录与协议号：QR/手机号/2FA、Session 加密、多账号文件（服务层已加入，待 Telegram 实际联调）。
3. SaaS 身份认证：邮箱注册验证、登录、密码重置、Token 轮换、租户切换、限流（已加入，待数据库/邮件环境联调）。
4. 会员等级与功能权限：FREE/BASIC/PRO/ENTERPRISE、频道/表情包克隆门槛、账号和任务数量限制（已加入）。
5. 账号资产：对话/群组/频道元数据、Bot 发现、权限检查、分页与断点续扫。
6. 资源发现：Telegram 可用搜索、指定搜索 Bot 结果解析、链接导入/类型识别/有效性检测、用户主动加入。
7. 克隆同步：时间和类型筛选、媒体/相册、历史+实时、防重复、编辑/删除同步、断点恢复。
8. 内容规则与 AI：文本替换、规则预览、验证识别翻译和用户协助；不绕过 CAPTCHA。
9. 商业化上线：支付、监控、备份、压力测试、安全审查、灰度上线。
