## 当前准备

统一README、项目规划、路线图、任务清单和工作流；提供PR/Issue模板及只读静态CI。Python/SQL检查不代表数据库或实网通过。CI在GitHub尚未执行，仓库分支保护尚未设置。

scripts/prepare_github.py以显式清单打包GitHub候选ZIP，生成每文件SHA-256清单和本地核对报告。不会修改Git索引或执行网络操作。CI配置采用官方actions示例的checkout/setup-python版本，见 https://github.com/actions/checkout 和 https://github.com/actions/setup-python 。

候选包含应用、测试、当前SQL、原始001～003、必要脚本、项目文档、验证快照与.github配置。不包含.local/.tools、.git历史、原始ZIP/旧交付ZIP、日志/数据库/备份、TG会话、旧原型、一次性源码修改工具和冗长内部接续历史。旧引导脚本保留作待修复记录，README明确其不能开箱即用部署。
